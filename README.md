# E-Commerce Sales Data Analysis (Power BI)

## Overview
This project explores e-commerce sales data using Power BI to import, transform, model, and analyze business performance across regions, product categories, and sales targets.

## Steps Completed
- **Data Transformation (Power Query):** Cleaned data, restricted rows, formatted text case, created custom columns (`Profit Margin`, `Profit Status`), merged columns (`Location`), and handled missing values.
- **Data Merging & Aggregation:** Joined order details with order lists into an `Orders Data` table and aggregated targets and sales performance.
- **Data Modeling:** Modeled 1-to-Many and Many-to-Many relationships across `List of Orders`, `Order Details`, and `Sales Target`.
